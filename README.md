# 🏥 Sistema de Gestión de Citas Médicas - Clínica

Aplicación de escritorio desarrollada en Java para simular el funcionamiento de una clínica médica, permitiendo la gestión de citas, pacientes y médicos.

---

## 🛠️ Tecnologías

- Java
- Java Swing / JavaFX (según aplique)
- NetBeans

---

## 🧩 Funcionalidades

- Registro de pacientes
- Agendamiento de citas por especialidad y doctor
- Gestión de historial de consultas
- Interfaz de usuario simple para interacción básica

---

## 🖥️ Instrucciones

1. Abre el proyecto en tu IDE Java (recomendado NetBeans)
2. Ejecuta `Main.java`
3. Interactúa desde el menú para probar funcionalidades
